# 1. Nama Proyek

I Like PDF — Aplikasi Konversi File PDF dan Word Berbasis Web

## 2. Latar Belakang

Perkembangan teknologi membuat kebutuhan pengolahan dokumen digital semakin meningkat. Pengguna sering membutuhkan konversi file PDF ke Word maupun Word ke PDF untuk memudahkan pengeditan dan berbagi dokumen. Oleh karena itu, diperlukan aplikasi berbasis web yang dapat membantu pengguna melakukan konversi dokumen dengan mudah dan praktis.

## 3. Permasalahan

* Pengguna membutuhkan cara mudah untuk mengubah file PDF menjadi Word dan sebaliknya.

* Proses konversi dokumen terkadang memerlukan aplikasi tambahan.

* Pengguna membutuhkan layanan konversi yang praktis tanpa harus membuat akun.

## 4. Tujuan Sistem

Mengembangkan aplikasi berbasis web yang dapat membantu pengguna mengonversi file PDF ke Word dan Word ke PDF secara mudah, cepat, dan praktis, serta menyediakan fitur untuk mengunduh dan menghapus file hasil konversi.

## 5. Ruang Lingkup

* Aplikasi berbasis web tanpa fitur login dan registrasi.

* Mendukung konversi Word ke PDF dan PDF ke Word.

* Menyediakan fitur unggah, unduh, dan hapus file.

* Menggunakan Laravel sebagai backend, Python dengan `pdf2docx` untuk konversi PDF ke Word, serta LibreOffice untuk konversi Word ke PDF.

* File disimpan sementara dan dihapus secara otomatis setelah melewati batas waktu yang ditentukan.
